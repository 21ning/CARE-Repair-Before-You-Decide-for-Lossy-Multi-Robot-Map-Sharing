# Anonymous ICASSP paper package

Compile `care_icassp_draft.tex` from this directory with an IEEEtran-enabled
LaTeX installation. The repository includes the final figures, paired-CI
tables, statistical manifests and five complete natural-map accepted-layout
manifests used to audit the paper's numerical claims. The evidence package
covers the role-aware six-loss controlled matrix, matched sensing extensions,
generic reconciliation controls, codec-matched closest-work adaptations,
zero-byte/full-sync endpoints, the rejected auxiliary route-witness gate,
conditioned natural maps and non-tiled 4--32-agent validation.

The raw 100-map episode outputs are not bundled in the submission code
repository. They can be regenerated from the frozen code and configurations
documented in `../docs/REPRODUCIBILITY.md`; the runners write only to explicit,
empty output directories.

The primary endpoint in the controlled study is decision-critical seeker CSR;
overall robot completion is diagnostic because one-step observers create a
0.5 floor. Natural-map results are a negative external-validity boundary, not
evidence of a broad CARE advantage.
